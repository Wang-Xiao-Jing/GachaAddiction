# GachaAddiction — Fabric 1.21.11

[English](README_EN.md) | [中文](README.md)

一个视觉化抽卡/战利品展示模组，适用于 Minecraft 1.21.11（Fabric），当前模组版本为 1.1.4。

> 本分支是面向 Minecraft 1.21.11 的社区 Fabric 移植，不受 GachaAddiction 官方支持，原作者不负责该分支的开发、维护或问题处理。

打开战利品容器时，GachaAddiction 会用动画老虎机式的转盘界面替代标准物品栏界面，以更精彩的方式展示战利品。

当然您可以使用 空格 键跳过战利品或使用 ESC 键跳过所有动画

## 功能

- **抽卡式展示** — 战利品以转盘动画形式滚动展示，伴有干扰物品
- **支持所有战利品表** — 兼容所有原版战利品表及数据包添加的内容
- **稀有度颜色** — 物品稀有度以彩色选择框高亮显示
- **Lootr 兼容** — 完整支持 Lootr 战利品容器

## 依赖

- **必需**: Minecraft 1.21.11、Fabric Loader 0.19.5+、Fabric API、Forge Config API Port、Java 21+（服务端和客户端）
- **可选**: Lootr、FTB Quests、Mod Menu
