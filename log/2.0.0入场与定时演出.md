# 2.0.0 入场与定时演出

更新日期：2026-10-20。按已确认方案实现；Minecraft 1.21.1 / NeoForge 21.1.249。编辑器诊断、Data生成和游戏内视觉验收分别记录。

## 现代与现代2

- 首次入场600毫秒，现代的单件切换及现代2翻页使用300毫秒缩短版。
- 同屏物品共用一个入场时钟及帧快照，同步淡入、上浮16像素、缩放0.95到1；缩短版上浮8像素。
- 背景先渐亮并展开眼形光晕，物品于约80～450毫秒进入，边缘光在后段柔和增强。所有通道使用五次平滑曲线，缩短版按相同比例压缩时序。
- 时钟在第一帧实际绘制时启动，等待服务端结果的时间不消耗入场时长。
- 直接进入汇总的奖励也同步入场，当前可见物品共用同一个帧快照；纵向滚动换入内容使用300毫秒入场。展示区域及边框位置固定，只有物品上浮和微缩放。
- 物品在既有展示区域内变换，裁剪矩形保持固定；现代2的最小宽度64、间隔8、按长边等比缩放、超量分页保持不变。普通现代的单件模型也在其展示区域内裁剪。
- 入场完成后接受普通点击揭晓、继续及翻页；现有空格、Shift等明确跳过入口遵循原强制观看规则。
- Shader不可用时，回退物品绘制也应用相同位移、缩放、淡入与裁剪。

## 图腾柔光冲击

- 选中图腾进入激活阶段时，中心光核短暂增强，一圈柔和光环向外扩展，12个小光屑向外散开并淡出。
- 图腾轻微膨胀到1.04后收束；激活250毫秒，再接原有350毫秒下落。
- 冲击特效固定在触发位置，独立于物品下落；总生命周期600毫秒，只为选中的图腾播放。
- 颜色沿用当前演出色并混入柔白；形状通过GUI几何生成，无新增纹理或世界粒子。
- 特效不进入物品反射和悬浮轮廓的捕获过程。

## 箱子固定950毫秒

普通箱子与副类型箱子共用时长参数及进度计算：

| 阶段 | 时长 |
| --- | --- |
| 开盖 | 450 ms |
| 完全开盖、保持箱内光效 | 180 ms |
| 箱体下落 | 320 ms |
| 总计 | 950 ms |

普通箱子保留上划屏高1/4的触发条件。滑动只用于触发固定演出，未达到触发距离时保持闭合；触发后的继续拖动、重复点击不加速演出。时间线从首帧实际绘制启动。副类型箱子在选中放大结束后启动相同的950毫秒时间线。

保留明确的跳过操作及强制观看限制，结算、扣费、分轮小总览和最终总总览继续走原流程。
