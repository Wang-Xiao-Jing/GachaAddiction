# 2.0.0 现代抽奖动画

> 本文维护现代主类型及网格说明，并保留阶段检查记录。当前多选一/多连抽的小总览、横向重排和来源类型规则见[抽奖交互说明](2.0.0抽奖交互.md)，游戏验收以[当前清单](2.0.0验收清单.md)为入口。

日期：2026-10-19。目标：Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21。

## 入口与默认值

新增动画类型 gachaaddiction:modern，中文名“现代”，通过现有 GachaTypes / GachaTypeClients 注册；原有真实容器、奖励包和使用 GachaType 的兼容入口可选择此类型，不依赖 LDLib2。

客户端 gachaa_screen.default_gachaas_type 的默认值改为 gachaaddiction:modern。缺失类型的通用解码回退及 FTB 无效类型 ID 回退也改为现代；明确选择老虎机、LDLib2 或无动画的定义不变。已有客户端配置文件中的明确值不会自动改写，可在配置界面切换为现代。

公开卡池的独立结果屏幕与配置界面的老虎机小窗预览没有在本次改接现代动画；它们继续使用现有展示入口。没有修改服务端奖励生成、事务投递或网络协议。

## 展示与操作

- 稀有度使用现有 RarityUtil；等级大于 0 的奖励进入单件展示，0 及以下仅进入最终汇总。
- 单件初始为黑色剪影，背景颜色来自当前物品稀有度。点击开始从剪影揭晓为完整物品，过渡时间为 350 毫秒。
- 揭晓后再次点击直接切换下一件；过渡未结束时点击也会直接完成当前件并切换。
- 按空格立即跳过当前揭晓，并在本次序列中保持快速揭晓模式；之后点击下一件会直接显示完整物品。空格在已完整展示的物品上也可切到下一件。
- 按任一 Shift 直接结束全部单件展示并进入汇总，不继续播放剩余剪影。按键长按重复事件不会连续跳过多件。
- 全部单件完成后汇总当前开出的所有奖励，包含稀有度 0 及以下的物品。汇总物品按先横后纵每100毫秒出现一件；出现过程中点击后加速为每25毫秒一件，空格立即补全全部物品。全部出现后再点击返回；Escape 沿用现有屏幕退出行为。

第一次完整奖励快照固定为本次结果，后续自动拿取引起的容器内容重同步不重开揭晓或重复追加奖励。保留现有同物品/组件合并和稀有度排序配置。

## 排版与边框

单件区域边长为屏幕短边的 80%，水平、垂直居中。物品使用原版 GUI 渲染；名称位于该区域左上，数量“× 数量”位于右下，跟随大图的位置。长名称最多显示两行，可悬浮名称或数量查看完整物品 Tooltip。

汇总区域最大占屏宽 80%，先从左往右排列，再换行向下；物品保持原版16×16 GUI像素，外框18×18，框与框之间横、纵均间隔1像素，格距为19像素。按可用宽度计算列数，少量奖励居中，物品和框使用整数像素坐标。超过可见高度时按行向下滚动查看，底部提示滚轮操作。

逐项出现时提前固定完整列表的格子位置，已经出现的内容不会因新增行反复居中。未出现的格子不绘制物品、数量或边框，也不触发悬浮；滚动范围限制在已经出现的行内，随新行出现扩展。点击加速时从当前进度继续，重复点击不会重置或拖慢出现计时；空格补全不会退出汇总。

所有可见物品与边框绘制完成并提交后，再在高于边框的层级绘制原版悬浮描述；文字、背景及物品 Tooltip 组件一起置顶，避免描述被框线遮挡。不添加播报淡绿框或圆角卡片。

## ColorTooltips 边框兼容

当前项目声明的 ColorTooltips 依赖版本为 tl2VdYIy；已通过 IDEA 解析该版本的 ConfigManager、DynamicColorResolver、ColorFlowAnimator 与 TooltipRenderer，确认主模块可编译引用。新增 [ColorTooltipsBorderRenderer.java](../src/main/java/xiaojin/gachaaddiction/client/compat/colortooltips/ColorTooltipsBorderRenderer.java)，只在检测到该模组后调用。

现代汇总框读取 ColorTooltips 为当前完整 ItemStack 选择的样式，通过其公开接口解析配色与颜色修饰，并复用渐变流动、透明度及流动方向。颜色流动计时每帧更新一次，边框仍限制在18×18内部，保留1像素框间距；不复制或修改第三方渲染源码。

格子适配只调用边框接口，不向 ColorTooltips 的完整悬浮面板动画系统登记每个格子。实际物品描述仍走原版 Tooltip 入口及 ColorTooltips 自身的事件/Mixin，包括其标题栏、物品模型与描述动画。格子边框深度设为200，低于原版及 ColorTooltips 的400层描述，兼顾鼠标移开后的缓存淡出；当前实时描述继续在全部框线提交后置顶绘制。

未安装、关闭或本屏调用接口失败时，使用原稀有度方框；异常只记录一次并停用当前屏幕的兼容路径。没有新增依赖、修改构建开关、全局配置或第三方代码。实际 ColorTooltips 联机、样式重载与游戏内显示尚未验收。

## 着色器

使用原版 PostChain 管理物品目标及中间合成目标；通过原版渲染接口捕获当前物品的实际颜色和透明轮廓，再由 GLSL 生成黑色剪影、稀有度渐变、中心雾光、柔和放射光、方形粒子、揭晓闪光及物品边缘光。没有将概念图作为全屏贴图，也没有建立世界粒子实体。

- [shaders/post/modern.json](../src/main/resources/assets/gachaaddiction/shaders/post/modern.json)：原版后处理链，先合成再使用原版 blit 输出。
- [shaders/program/modern.json](../src/main/resources/assets/gachaaddiction/shaders/program/modern.json)：着色器参数及原版 blit 顶点程序引用。
- [shaders/program/modern.fsh](../src/main/resources/assets/gachaaddiction/shaders/program/modern.fsh)：渐变、雾光、粒子、剪影与轮廓合成。
- [ModernGachaEffect.java](../src/main/java/xiaojin/gachaaddiction/client/render/ModernGachaEffect.java)：原版物品目标、Uniform、窗口尺寸和资源重载生命周期。
- [ModernGachaScreen.java](../src/main/java/xiaojin/gachaaddiction/client/gui/screen/ModernGachaScreen.java)：交互状态、排版、奖励汇总与完成通知。

特效目标按屏幕实例复用，不在每帧重新创建；窗口物理尺寸、主目标或资源版本改变后重新创建。进入汇总或退出界面时释放目标。处理结束与加载失败后恢复主渲染目标、GUI 颜色、混合与深度状态。加载或运行失败会记录日志并降级到基础物品界面，同一资源版本和尺寸下不逐帧重试。

每个单件画面需要一次原版物品渲染和两次全屏 Pass，额外持有两个全分辨率目标。粒子直接由片段着色器计算，没有 CPU 粒子列表；高分辨率、集成显卡及其他光影组合的实际开销尚未测量。降级界面不具备完整的 Shader 特效。

按确认概念图实现上述布局和效果层次；尚未启动游戏逐帧对照，不能将静态诊断视为与概念图视觉完全一致的证明。

## 自动拿取、播报与语言

沿用BasicGachaScreen的OPEN请求和COMPLETE通知边界，当前真实容器默认只在OPEN自动拿取。完整揭晓、直接切换或Shift跳过时，每个最终RewardData最多触发一次完成通知；默认不会据此再次请求拿取。服务端许可、菜单、槽位与实际物品复核保持原样。

单件名称/数量以及汇总物品的原版 Tooltip 继续可供当前开箱会话的 Alt 播报入口使用；剪影不显示完整物品 Tooltip。容器淡绿标记仍由现有真实容器界面负责，不在大图或汇总格子增加绿色播报边框。

现代类型名称及六条界面文案维护在 TranslationKeys / LangHandler 生成源，已按后续请求通过 IDEA 的 Data 配置生成到中英文语言文件，没有手工修改生成 JSON。运行与核对结果见下节记录。

汇总加速提示`gui.gachaaddiction.modern.summary_reveal_hint`已由后续Data生成，2026-10-20读取中英文生成文件确认存在；本轮未再次运行Data。
