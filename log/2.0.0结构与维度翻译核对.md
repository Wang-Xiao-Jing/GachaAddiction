# 结构与维度翻译核对

> 本文是固定版本的名称来源核对记录。语言键总数对应当时Data快照；当前生成数量与未完成翻译见[文档索引](README.md#本次整理记录)，本轮未重新联网核对Wiki或指南针源码。

日期：2026-10-19。依据当前项目 Minecraft Java 1.21.1 / NeoForge 21.1.249 的实际依赖源码与资源，另对照 Minecraft Wiki 和两个指南针项目。未安装依赖或运行游戏；后续按请求通过 IDEA 完成 Data，退出码 0。

## 结论

1. 结构名称使用 structure.<namespace>.<path>，与指南针模组的读取约定一致；这不代表原版 Java 已经提供这些名称翻译。
2. 当前原版 assets/minecraft/lang/en_us.json 完整解析后共 6881 个键，其中 structure.* 和 dimension.* 均为 0 个。结构 API 也没有与 Level#getDescription() 对等的描述方法。
3. NeoForge 为维度提供正式 API：ILevelExtension#getDescriptionKey()、getDescription()，前缀为 dimension。NeoForge 的 assets/c/lang/en_us.json 已提供三个原版维度的名称。
4. Wiki 的 Java 结构 ID、基岩版 feature.* 键、原版 filled_map.* 地图名称是不同对象，不能混用。
5. 两个指南针项目都自己提供 structure.* 语言条目；不安装相关模组/资源包时，单独生成键不能凭空得到中文结构名。
6. 已按确认的 A 方案实现：结构标准键优先，缺失时读取本模组的 34 种原版结构中英文回退；回退也缺失时显示资源 ID。维度直接使用 Level#getDescription()，按此次要求补充三个原版标准维度键的中英文生成条目；结构标准键保持不覆盖。

## 原版与 Wiki

IDE 中读取了当前 neoforge-21.1.249-merged.jar 的 BuiltinStructures、Structure、ResourceLocation、Util、ILevelExtension，以及 neoforge-21.1.249-client-extra-aka-minecraft-resources.jar 中完整 en_us.json。

BuiltinStructures 声明了 34 个配置结构 ID。应使用实际注册到 Registries.STRUCTURE 的 ID，不使用结构类型 ID、战利品表 ID 或 NBT 模板路径。例如：

| 对象 | 正确例子 | 不应替代为 |
|---|---|---|
| 末地城结构 | minecraft:end_city → structure.minecraft.end_city | 老版本 endcity，或基岩版 feature.end_city |
| 丛林神庙结构 | minecraft:jungle_pyramid → structure.minecraft.jungle_pyramid | 结构类型 jungle_temple |
| 林地府邸结构 | minecraft:mansion → structure.minecraft.mansion | 类型 woodland_mansion、NBT 模板目录或 filled_map.mansion |
| 海底废墟 | ocean_ruin_cold / ocean_ruin_warm | 合并的旧 ocean_ruin |
| 村庄 | village_plains 等 5 个实际配置 ID | 合并的旧 village |
| 试炼密室 | minecraft:trial_chambers → structure.minecraft.trial_chambers | 地图名 filled_map.trial_chambers |

[Wiki 生成结构表](https://zh.minecraft.wiki/w/%E7%94%9F%E6%88%90%E7%BB%93%E6%9E%84?variant=zh-tw)区分 Java 与基岩版 ID；本轮全文直接访问受限，读取了搜索索引返回的结构表，并以本地 1.21.1 的 BuiltinStructures 逐项定准版本。没有把 Wiki 最新版本条目当作当前依赖 API。

[Wiki 末地城数据值](https://uk.minecraft.wiki/w/%D0%9C%D1%96%D1%81%D1%82%D0%BE_%D0%95%D0%BD%D0%B4%D1%83#ID)将 feature.end_city 放在基岩版表中；Java 表列的是结构 ID。[Wiki 探险家地图](https://minecraft.fandom.com/wiki/Explorer_Map#Data_values)中的 filled_map.* 对应地图物品名称，本地原版语言文件也确认包含这些键。它们不是通用结构名称。

本地 1.21.1 Util.makeDescriptionId 与 ResourceLocation.toLanguageKey 采用相同的点分组合规则，并将路径中的斜线转为点。本轮结构代码沿用此规则。

## 指南针模组对照

### Structures Compass（Samarium150）

读取 [build.gradle](https://github.com/Samarium150/StructuresCompass/blob/main/build.gradle) 后确认 main 对应 1.18.2，而不是本项目版本。其 [StructureUtils](https://github.com/Samarium150/StructuresCompass/blob/main/src/main/java/io/github/samarium150/minecraft/mod/structures_compass/util/StructureUtils.java) 在客户端按结构类型注册名拼接 structure 前缀。

[中文语言文件](https://github.com/Samarium150/StructuresCompass/blob/main/src/main/resources/assets/minecraft/lang/zh_cn.json)由模组自己提供，位于模组资源中的 assets/minecraft 下；这个路径不表示它来自原版。包含 endcity、ocean_ruin、village 等老键，不能把整份文件直接套到 1.21.1 的配置结构注册表。

### Explorer’s Compass（MattCzyr）

核对实际 neoforge-1.21.1 分支，固定快照 commit 为 53fb4478fc44197d4d159c9e83928368ed1e0f45。其属性文件 mod_version 为 1.21.1-3.4.0-neoforge；没有使用当前 main 的 26.3 API 作为本项目实现依据。

[StructureUtils#getPrettyStructureName](https://github.com/MattCzyr/ExplorersCompass/blob/53fb4478fc44197d4d159c9e83928368ed1e0f45/src/main/java/com/chaosthedude/explorerscompass/util/StructureUtils.java#L171)读取 Util.makeDescriptionId 生成的 structure 键，缺失时把注册路径整理成英文单词。[中文翻译](https://github.com/MattCzyr/ExplorersCompass/blob/53fb4478fc44197d4d159c9e83928368ed1e0f45/src/main/resources/assets/explorerscompass/lang/zh_cn.json)位于模组的 assets/explorerscompass/lang/zh_cn.json，由该模组提供而非原版内置。

将此快照的语言键与当前原版 34 个结构 ID 对照：

- 中文覆盖 33/34，缺少 trial_chambers。
- 英文覆盖 31/34，缺少 ancient_city、trail_ruins、trial_chambers。
- 另保留 endcity、ocean_ruin、village 三个当前配置注册表中不存在的旧键。
- 结构组（StructureSet）与具体配置结构不是同一个注册表，本轮播报应使用后者。

## 对当前实现的影响

- 已确认现有结构键构造与指南针约定一致，继续兼容其他模组或资源包提供的标准键。
- 维度复用 NeoForge Level#getDescription()，保持接收者语言和资源包解析。
- 原版结构缺少相应标准翻译时，读取本模组的 gachaaddiction.structure_fallback.minecraft.<path>；34 个中英文回退条目已加入 TranslationKeys 生成源。不会使用生物群系名、地图名、基岩版键、结构类型或战利品表名称冒充结构名。
- 标准键由 I18n.exists 优先检查；本模组只定义独立回退键，不增加指南针依赖，不覆盖其他模组或资源包已有的标准译文。模组结构无译文时仍显示资源 ID。
- 已按请求通过 IDEA 运行 Data，退出码 0。实际生成的 en_us（451 项）及 zh_cn（438 项）均包含全部 34 个结构回退键、三个原版维度键和新增播报文案；执行记录、非阻断的 LDLib2 日志错误及备份详见 [开箱播报文档](2.0.0开箱播报.md)。
