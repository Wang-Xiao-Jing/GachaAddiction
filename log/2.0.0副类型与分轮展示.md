## 已实现

- [x] 图腾使用触发物的FIXED物品模型，沿原版轨迹到达近处并转正；宝箱副类型独立使用透视箱体入场并转向正面，不因触发物是箱子而切换图腾动画。
- [x] `select_one`：多个缩小对象同时入场，悬浮显示白色轮廓；点击后选中对象放大、触发并下落，其余对象缩小下落，无需第二次点击。选择只影响展示，不改变抽奖概率或奖励。
- [x] `multiple`：对象对应服务端实际抽奖轮次，同时出现；点击一个后展示该轮奖励，再返回其余对象，最后展示全部奖励。
- [x] 两种副类型独立选择，适用于图腾、宝箱。未启用副类型的宝箱保留上划打开。
- [x] 保留空格快速跳过及强制观看限制；候选单行横向排列，超出可见宽度后使用滚轮横向滚动。
- [x] 来源能力设置、客户端配置、偏好同步及结果消息接入副类型和真实分轮数据。
- [x] 多个相同宝箱在同一帧复用场景纹理，避免每个对象重复渲染模型。

## 配置与接口

客户端 `gachaa_screen.secondary_type` 可选 `none`、`select_one`、`multiple`，默认 `none`。`gachaa_screen.choice_count` 控制多选一候选数量，默认3，范围2～12。

`GachaSourceSettings` 新增 `Optional<GachaSecondaryType> secondaryType`、`int choiceCount`，保留原双参数构造方式。来源显式设置优先于客户端偏好；未设置时使用客户端偏好。

物品沿用 `minecraft:custom_data` 中的 `gachaaddiction` 数据，例如：

```snbt
{gachaaddiction:{gacha_type:"gachaaddiction:totem",secondary_type:"select_one",choice_count:3}}
```

多连抽使用 `secondary_type:"multiple"`；轮数由服务端卡池或抽奖包的执行计划决定，`choice_count` 不增加抽数。方块实体、实体通过已有来源能力和附件 Codec 保存同名设置。

`GachaExecutionResult`、`GachaTransactionResult` 和两种结果消息新增 `rewardRounds`，旧构造方式默认无分轮信息。网络协议升级为4，客户端和服务端需要一同更新。

## 结算与兼容边界

复杂连抽完整流程用于卡池及有服务端抽奖绑定的特殊物品。普通固定容器没有真实分轮结果时回退为单次展示，不额外生成或扣取奖励。

特殊物品仍在首次触发完成后确认一次事务；卡池结果沿用原有已提交事务。后续点击只揭晓已结算的相应轮次，不重复扣费、抽取或发奖。

轮次在实际生成阶段记录并传递，支持保留来源轮次的数量、来源信息等修改。规则生成无法追踪轮次的新奖励、混入直接成品奖励或轮数超出展示上限时，回退为整体展示，不按扁平奖励数量猜测分轮。展示最多4096轮，结果消息仍受原有4096物品堆上限约束。

分轮信息仅用于当次展示，不写入事务恢复日志；原有资产恢复流程保持原样，断线恢复不续播分轮界面。

### 测试命令

多选一可直接使用原版末地城战利品箱测试，右键生成的箱子：

```mcfunction
/setblock ~ ~ ~2 minecraft:chest{LootTable:"minecraft:chests/end_city_treasure","neoforge:attachments":{"gachaaddiction:gacha_source":{gacha_type:"gachaaddiction:chest",secondary_type:"select_one",choice_count:3,force_watch:0b}}}
```

应同时出现3个横向并排的箱子并播放入场、转正；选中后该箱放大、开盖下落，其余缩小下落。单次只显示小总览，结束后直接关闭。

```mcfunction
/give @s gachaaddiction:sealed_chest[minecraft:custom_data={gachaaddiction:{card_pool:"gacha_test:secondary_demo",package:"gacha_test:triple",gacha_type:"gachaaddiction:chest",secondary_type:"multiple",force_watch:0b}}]
```

手持右键后对象数量应对应套餐实际轮数，逐个点击、查看该轮奖励、返回继续，最终汇总。可用 `/gacha admin list card_pools` 查看生效卡池ID，使用 `/gacha open` 进入卡池，在套餐确认页查看套餐ID和实际执行轮数。单轮套餐不能用于验证多连抽，普通容器也不会因设置 `multiple` 产生额外抽数。
