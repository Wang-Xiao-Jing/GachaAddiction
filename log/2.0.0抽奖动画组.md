## 动画与交互

| 类型 ID | 前段表现 | 操作 | 结束 |
| --- | --- | --- | --- |
| `gachaaddiction:chest` | 45°俯视3D箱子，复用有效来源宝箱模型，三维光束与物品跳出 | 点击宝箱四次；空格跳过；开盖中再次点击立即完成 | 现代汇总 |
| `gachaaddiction:csgo` | 横向物品带，固定中央指针 | 拖动底部滑杆至至少20%后松手启动；点击刹车；再次点击或空格跳过 | 现代汇总 |
| `gachaaddiction:wheel` | 十二格转盘，顶部固定指针 | 沿转盘拖动至少约五分之一圈后松手启动；点击刹车；再次点击或空格跳过 | 现代汇总 |
| `gachaaddiction:slot_machine` | 原有纵向多转轮布局，现代背景与候选洗牌持续循环 | 点击或空格开始停轮，之后填入真实物品；再次点击或空格快速完成 | 现代汇总 |
| `gachaaddiction:interactive_slot_machine` | 三轴老虎机与右侧拉杆 | 拉杆向下拖动至少面板高度20%后松手；从左到右点击三个停轴按钮，或按1/2/3；空格跳过 | 现代汇总 |
| `gachaaddiction:totem` | 立体图腾模型进入、三轴摇摆与退出 | 自动播放约2.4秒；空格跳过 | 现代汇总 |
| `gachaaddiction:modern` | 已有大图剪影、稀有物品逐件揭晓 | 沿用点击、空格和Shift操作 | 现代汇总 |

一般刹车时长为700毫秒，3D宝箱开盖与物品跳出演出为1400毫秒。旧老虎机停轮按速度与距离限制在850～3200毫秒，停稳短暂停留后进入汇总。每帧按时间推进，拖动、加速与刹车不向服务器传递抽奖参数。上述数值集中在动画类常量中。

现代仍为默认动画。其单件展示规则保持：稀有度0及以下不单独展示，其他先展示黑色剪影；大图按屏幕短边80%居中。各前段的结尾复用同一现代汇总：16×16物品、18×18外框、框间1像素；每100毫秒出现一件，点击改为25毫秒，空格立即显示全部，超出向下滚动，悬浮说明置于边框之后，保留ColorTooltips兼容。旧老虎机保留原ID和纵向布局，已有选择`slot_machine`的配置使用升级后的循环演出；新三轴老虎机通过`interactive_slot_machine`单独选择。

## 打开触发与完成触发

- 原版容器只在打开阶段请求自动拿取，仍受独立的客户端意愿与服务端许可控制；动画不重新抽取容器战利品。
- 现有兼容入口已经发放的奖励，继续作为展示快照，不因观看动画再次扣除或发放。
- 新专用道具先由服务端检查卡池、套餐、可用性和客户端通道并创建待确认会话。观看前不执行真实抽奖或消耗。
- 正常结束或空格跳过后，客户端只发送一次完成请求。服务端重新核对会话归属、期限、维度、存活状态和当前手持道具组件，再使用现有事务系统执行卡池消耗、道具消耗及奖励发放。
- 卡池原有库存消耗与一个启动道具合并为同一库存预留，先匹配启动道具的完整组件，沿用事务日志、返还与奖励收件箱。创造模式沿用现有免消耗规则。
- 展示会话号与实际卡池确认令牌分离；客户端无法通过普通确认通道省掉道具消耗。重复完成请求由服务端提交状态挡住。
- 结算前退出取消待确认会话，不消耗。已经提交时关闭界面不撤销事务，结果仍按原有投递/恢复规则处理。迟到回复只更新匹配的当前界面，不重新打开已经退出的界面。
- 奖励按卡池既有投递策略处理，动画本身不承诺直接背包投递，不新增概率、奖品表或默认卡池。

## 专用道具与服主绑定

| 物品 ID | 对应动画 | AI纹理 |
| --- | --- | --- |
| `gachaaddiction:sealed_chest` | 宝箱 | `textures/item/sealed_chest.png` |
| `gachaaddiction:gacha_key` | CSGO | `textures/item/gacha_key.png` |
| `gachaaddiction:wheel_ticket` | 转盘 | `textures/item/wheel_ticket.png` |
| `gachaaddiction:slot_token` | 交互式老虎机（`interactive_slot_machine`） | `textures/item/slot_token.png` |
| `gachaaddiction:wish_totem` | 图腾 | `textures/item/wish_totem.png` |

五种物品加入工具与实用物品栏。无卡池绑定的道具提示联系服主，不自动选择任何卡池。服务端读取物品的 `minecraft:custom_data` 下 `gachaaddiction` 复合标签：

```mcfunction
/give @s gachaaddiction:wheel_ticket[minecraft:custom_data={gachaaddiction:{card_pool:"example:pool",package:"example:single",preview_items:["minecraft:diamond","minecraft:emerald"]}}]
```

`example:pool` 与 `example:single` 必须替换为已经部署的公开卡池及其中的套餐 ID。套餐使用已有默认轮数与参数；需要玩家另行选择参数的复杂套餐应继续使用原有公开卡池界面。

`preview_items` 可选，最多读取24个非空物品 ID，仅供演出；缺省使用卡池图标。服务端返回真实结果前，专用道具界面明确标注“演示图标”。此列表不改变任何候选、权重、数量或实际结果。

资源包可以分别替换五张PNG和物品模型。祈愿图腾使用分段立体几何，其余道具采用双面平面，避免对1254×1254透明轮廓执行逐像素挤出。AI原图保留透明通道，未执行离线缩放；当前尺寸不是2的幂，纹理图集占用与mipmap层级需要游戏内确认，发布前应考虑专门的低分辨率资源导出。
